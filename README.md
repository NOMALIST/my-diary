# 한 줄 일기

일기를 쓰면 AI가 한 줄로 요약하고, 한 주·한 달을 회고해 주는 로컬 전용 앱.

## 기능
- **오늘 일기**: 날짜별 일기 작성 → 한 줄 요약 + 감정 이모지 + 키워드
- **주간 회고**: 한 주(월~일) 일기 → 한 줄 요약 + 잘한 점 / 개선할 점 / 다음 주 액션
- **월간 회고**: 한 달 일기 → 한 줄 요약 + 이달의 테마 / 잘한 점 / 개선할 점 / 다음 달 목표

## 동작 방식
- AI 호출: 로그인된 **Claude Code CLI**(`claude -p`)를 서버에서 실행 → 구독 플랜 사용, API 키 불필요
- 저장: 프로젝트 폴더 `data/diary.json` (일기 + 모든 요약 결과)
  - 첫 저장 시 자동 생성
  - 개인 기록이므로 `.gitignore`에 포함
- 본인 PC 로컬 전용 — 배포·타인 제공 불가

## 사전 준비
- Node.js 20+
- Claude Code 설치 및 로그인 (`claude` 실행 후 로그인)

## 실행
```bash
npm install
npm run dev
```
→ http://localhost:3000 (단독 실행 기본값)
- 포트 지정: `PORT` 환경변수 또는 `npm run dev -- -p <포트>`
- 알프레드(my-tool-box)로 실행 시 배정 포트(3100)가 `PORT`로 전달됨

## 설정 (선택)
- `CLAUDE_MODEL`: 사용할 모델 별칭 (기본 `sonnet`, 예: `opus`, `haiku`)

## 주의
- 요약 1회당 수 초 소요 (CLI 기동 포함), 월간 회고는 더 오래 걸릴 수 있음
- Claude Code 사용량 한도를 함께 사용
- 백업: `data/diary.json` 파일만 복사하면 됨
